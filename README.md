# MilkMate - Dairy Milk Management System

MilkMate is a web-based Dairy Milk Management System developed using Spring Boot, MySQL, HTML, CSS and JavaScript.

## Features

### Admin Module
- Admin Login
- Admin Dashboard
- Farmer Management
- Milk Collection Management
- Milk Rate Management
- Payment Management
- Monthly Accounts
- Reports
- Notifications
- Milk Collection Analytics

### Farmer Module
- Farmer Login
- Farmer Dashboard
- Daily Milk Collection
- My Milk Records
- Payment Details
- Farmer Profile
- Notifications
- Monthly Milk and Amount Summary

## Technology Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- HTML5
- CSS3
- JavaScript
- Maven

MySQL is used as the database.
